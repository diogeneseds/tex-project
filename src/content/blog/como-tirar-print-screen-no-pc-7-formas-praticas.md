## O que é tirar Print Screen? Como fazer?

**Tirar Print Screen**, também conhecido como **captura de tela**, é o ato de registrar a imagem exibida no seu computador ou notebook. No Windows, você pode pressionar a tecla **“Print Screen” (ou “PrtSc”)** para capturar a tela inteira e depois apertar "Ctrl + C" para colar no Word ou Paint. Esse é o método mais comum de tirar print screen, porém, existem várias outras maneiras de tirar prints de tela no PC com Windows. Aqui estão sete formas diferentes para você escolher:

## 1\. Teclas Alt + Print Screen

As teclas "Alt + Print Screen" são uma maneira eficiente de capturar a janela ativa no seu PC com Windows. Quando você pressiona Alt + PrtScr, a imagem da janela ativa é copiada para a Área de Transferência. Isso significa que você pode colá-la diretamente em um software de edição, como o Paint, para fazer ajustes ou salvá-la como um arquivo de imagem.

Essa técnica é especialmente útil quando você deseja capturar apenas o conteúdo de uma janela específica, excluindo a Barra de Tarefas e outros elementos da tela.

## 2\. Tecla Windows + Alt + PrtScr: captura a tela inteira.

Essa combinação de teclas é como um portal mágico para capturar a tela inteira no seu PC com Windows. Siga esses passos para dominar essa técnica:

- **Localize as Teclas Certas:** Encontre a tecla Windows no seu teclado (tem geralmente o ícone da janela do Windows). Ao lado dela, você verá a tecla Alt. Por fim, procure a tecla PrtScr (Print Screen).

- **Pressione as Teclas Simultaneamente:** Mantenha pressionadas as teclas Windows + Alt + PrtScr ao mesmo tempo. A tela inteira será capturada e salva na Área de Transferência.

- **Aperte Windows + G para abrir a Game Bar:** Pressione as teclas "Windows + G" para abrir a Game Bar e identificar a imagem. No canto superior esquerdo, clique em "Ver minhas capturas" e será listada todas as capturas, sendo possível alternar entre elas ou excluir.

## 3\. Teclas Windows + Print Screen:

As teclas "Windows + Print Screen" são uma maneira rápida e eficaz de capturar a tela inteira no seu PC com Windows. Siga esses passos para dominar essa técnica:

- Acesse a Tela Desejada

- Pressione a tecla "Print Screen", localize-a no seu teclado, geralmente encontrada no canto superior direito, ao lado das teclas de função (como F12).

- Pressione a tecla Print Screen. Ela capturará tudo o que está em exibição na tela.

- Abra o Paint (Programa Editor de Imagem do Windows).

- Cole a Imagem Capturada (pressione Ctrl + V para colar a imagem capturada)

Essa técnica é especialmente útil quando você deseja capturar a tela inteira.

## 4\. Teclas Windows + Shift + S:

Quando você pressiona essa combinação de teclas, a área de trabalho escurece ligeiramente, permitindo que você selecione uma área específica para a captura de tela. Por padrão, o modo retangular é acionado para seleção da captura.

Características: Permite capturar parte da tela (desenhando a área com o mouse) ou a tela inteira.

**Passo a passo:**

- Siga o atalho pressionando as Teclas "Windows + Shift + S" do teclado.

- Selecione a área com o modo retangular.

- A área selecionada será capturada e salva na Área de Transferência

- A imagem aparece como uma notificação lateral do Windows, caso clique na notificação, ela pode ser editada e salva.

- Como o print fica salvo na área de transferência, pode-se colar o mesmo em um programa de edição (Paint).

## 5\. Atalho Ctrl + P para criar um .pdf:

- Pressione "Ctrl + P" para imprimir a tela atual como um arquivo PDF.

## 6\. Ferramenta de Captura do Windows:

**Procedimento passo a passo:** 

- Abra a **[Ferramenta de Captura](https://support.microsoft.com/pt-br/windows/abrir-a-ferramenta-de-captura-e-fazer-uma-captura-de-tela-a35ac9ff-4a58-24c9-3253-f12bac9f9d44)**

- No Menu Iniciar, pesquise por “Ferramenta de Captura” e selecione-a nos resultados.

- Clique na ferramenta de "tesourinha" escrito "Novo" para fazer uma captura de tela.

- Escolha o modo desejado na barra de ferramentas.

A captura será copiada para a Área de Transferência, pronta para edição ou compartilhamento.

## 7\. Xbox Game Bar:

A Xbox Game Bar é uma ferramenta incrível embutida no Windows 10 e 11, especialmente para os entusiastas de jogos. Ela oferece uma variedade de recursos úteis para melhorar sua experiência de jogo e interação com amigos. Um desses recursos é a Captura de tela, onde é possível gravar clipes de jogos ou fazer capturas de tela.

- Pressione Windows + G para abrir a barra de jogos.

- Clique em “Capturar” para tirar um print da tela.

## Onde ficam salvas as imagens de Print Screen?

Quando você tira um print screen no seu PC, a imagem é salva automaticamente em uma pasta específica. O local exato pode variar dependendo do sistema operacional que você está usando.

### Windows 10

No Windows 10, as imagens de print screen são salvas na pasta "Capturas de tela" dentro da pasta "Imagens". Para acessar essa pasta, abra o Explorador de Arquivos (Explorer) e navegue até "Este Computador" > "Imagens" > "Capturas de tela".

### Windows 8 e 8.1

No Windows 8 e 8.1, as imagens de print screen são salvas na pasta "Capturas de tela" dentro da pasta "Imagens". Para acessar essa pasta, abra o Explorador de Arquivos e navegue até "Este Computador" > "Imagens" > "Capturas de tela".

### Windows 7

No Windows 7, as imagens de print screen são salvas na pasta "Capturas de tela" dentro da pasta "Imagens". Para acessar essa pasta, abra o Explorador de Arquivos e navegue até "Bibliotecas" > "Imagens" > "Capturas de tela".

### Outros sistemas operacionais

Se você estiver usando um sistema operacional diferente, pode ser necessário fazer uma pesquisa rápida para descobrir onde as imagens de print screen são salvas. Em geral, elas são salvas em uma pasta chamada "Capturas de tela" ou "Print Screens".

Se preferir capturar apenas uma área específica, a ferramenta de captura do Windows é a melhor opção. Além disso, se você deseja compartilhar a imagem rapidamente, o atalho do Windows + Print Screen salva automaticamente a imagem na pasta de capturas de tela.
